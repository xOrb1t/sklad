# Sklad — Telegram-бот для учёта склада

Телеграм-бот и веб-панель для управления складскими позициями: добавление товаров с фото, поиск (артикул, ссылка Avito, текст, фото, голос), изменение остатков и удаление. Распознавание речи и анализ фото — через модели Groq (опционально).

## Требования

- [Docker](https://docs.docker.com/get-docker/) ≥ 24
- [Docker Compose](https://docs.docker.com/compose/) v2 (включён в Docker Desktop)

## Быстрый старт

```bash
git clone <url-репозитория>
cd sklad
cp .env.example .env
# Откройте .env и заполните BOT_TOKEN (и при желании GROQ_API_KEY, WEB_BASE_URL)
docker compose up -d
```

При первом запуске Docker соберёт образ, запустит PostgreSQL, применит миграции и поднимет бота и веб-панель (`127.0.0.1:8080`).

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|:------------:|---------|
| `BOT_TOKEN` | ✅ | Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather) |
| `DATABASE_URL` | ✅ | URL подключения к PostgreSQL. По умолчанию: `postgresql+asyncpg://sklad:sklad@db:5432/sklad` |
| `GROQ_API_KEY` | — | API-ключ [Groq](https://console.groq.com/). Без него поиск по фото/голосу отключён |
| `GROQ_VISION_MODEL` | — | Vision-модель. По умолчанию `meta-llama/llama-4-scout-17b-16e-instruct` |
| `GROQ_WHISPER_MODEL` | — | Модель распознавания речи. По умолчанию `whisper-large-v3-turbo` |
| `WEB_BASE_URL` | — | Публичный адрес панели, из него бот строит ссылку `/web`. По умолчанию `http://localhost:8080` |
| `WEB_SECRET` | — | HMAC-ключ ссылок входа и cookie. Пусто — выводится из `BOT_TOKEN` (смена токена разлогинит всех) |
| `WEB_LOGIN_TTL` / `WEB_SESSION_TTL` | — | Время жизни ссылки входа (600 с) и сессии (7 дней) |

> **Важно:** `file_id` фото товаров привязан к токену бота (D005). При смене `BOT_TOKEN` ранее сохранённые фото станут недоступны — потребуется повторная загрузка изображений.

## Команды бота

| Команда | Действие |
|---------|----------|
| `/start` | Регистрация продавца |
| `/myproducts` | Список товаров → карточка: ±1, количество, редактирование любого поля (название, описание, артикул, Avito, фото), удаление с подтверждением |
| `/addproduct` | Пошаговое добавление: фото → название → описание → артикул → ссылка Avito → количество |
| `/search <запрос>` | Каскад: ссылка Avito → точный артикул → подстрока в названии/описании/артикуле |
| `/web` | Ссылка для входа в веб-панель |
| `/cancel` | Выход из пошагового ввода |
| Количество | `12` — задать, `+5` / `-3` — изменить относительно текущего; при редактировании `-` очищает необязательное поле |
| текст / фото / голос | Быстрый поиск; фото и голос — через Groq (ключевые слова, ранжирование по совпадениям) |

## Веб-панель

Сводка (позиций, единиц, нет в наличии, мало, с фото, на Avito), поиск, фильтр по остаткам, ±1 к количеству, добавление/редактирование/удаление, экспорт в CSV (`;`, UTF-8 с BOM — открывается в Excel).

Фото хранятся как Telegram `file_id`, как и в боте: панель проксирует их из Telegram, а загруженное через веб фото бот тихо отправляет в ваш чат с ним (чтобы получить `file_id`) и сразу удаляет это сообщение. Поэтому для загрузки бот не должен быть заблокирован.

**Вход:** команда `/web` в боте → одноразовая ссылка (по умолчанию 10 минут) → cookie-сессия (HttpOnly, SameSite=Lax, `Secure` при `https://` в `WEB_BASE_URL`). Пишущие запросы дополнительно требуют заголовок `X-Sklad: 1` (CSRF). Если Telegram недоступен:

```bash
docker compose exec web python -m web.login <telegram_id>
```

По умолчанию порт опубликован только на `127.0.0.1` — наружу панель выставляйте через reverse proxy с TLS (пример labels для Traefik — в `docker-compose.yml`).

## Управление

### Остановить бота

```bash
docker compose down
```

### Остановить и удалить данные БД

```bash
docker compose down -v
```

### Просмотр логов

```bash
docker compose logs -f bot web
```

### Просмотр логов миграций

Миграции выполняются при каждом старте контейнера `bot`. Строки `INFO  [alembic.runtime.migration]` в начале лога подтверждают успешное применение миграций.

## Разработка

```bash
pip install -r requirements.txt
BOT_TOKEN=123:x pytest -q
```

Тесты используют SQLite в памяти, Telegram и Groq не нужны.
