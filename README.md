# Sklad — Telegram-бот для учёта склада

Телеграм-бот для управления складскими позициями: добавление товаров с фото и голосовым описанием, поиск, просмотр и удаление позиций. Распознавание речи и анализ фото выполняются через модели Groq.

## Документация

- [Контекстная база позиций и поиск по фото/описанию](docs/context-base.md) — дизайн схемы, пайплайнов наполнения и гибридного поиска, план работ.

## Требования

- [Docker](https://docs.docker.com/get-docker/) ≥ 24
- [Docker Compose](https://docs.docker.com/compose/) v2 (включён в Docker Desktop)

## Быстрый старт

```bash
git clone <url-репозитория>
cd sklad
cp .env.example .env
# Откройте .env и заполните BOT_TOKEN и GROQ_API_KEY
docker-compose up -d
```

При первом запуске Docker соберёт образ, запустит PostgreSQL и применит миграции базы данных — бот начнёт работу автоматически.

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|:------------:|---------|
| `BOT_TOKEN` | ✅ | Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather) |
| `GROQ_API_KEY` | ✅ | API-ключ [Groq](https://console.groq.com/) для распознавания фото и голоса |
| `DATABASE_URL` | ✅ | URL подключения к PostgreSQL. По умолчанию: `postgresql+asyncpg://sklad:sklad@db:5432/sklad` |

> **Важно:** `file_id` фото товаров привязан к токену бота (D005). При смене `BOT_TOKEN` ранее сохранённые фото станут недоступны — потребуется повторная загрузка изображений.

## Используемые модели Groq

| Назначение | Модель |
|------------|--------|
| Анализ фотографий товаров | `llama-3.2-vision-preview` |
| Распознавание голосовых сообщений | `whisper-large-v3-turbo` |

## Управление

### Остановить бота

```bash
docker-compose down
```

### Остановить и удалить данные БД

```bash
docker-compose down -v
```

### Просмотр логов

```bash
docker-compose logs -f bot
```

### Просмотр логов миграций

Миграции выполняются при каждом старте контейнера `bot`. Строки `INFO  [alembic.runtime.migration]` в начале лога подтверждают успешное применение миграций.
